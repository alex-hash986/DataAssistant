# Data Assistant

AI-чат на FastAPI + Jinja2 + HTMX, который использует OpenAI API для ответов по данным и анализа изображений, а локально строит графики и сохраняет артефакты в файлы.

## Что умеет

- принимать обычные текстовые сообщения;
- загружать CSV, Excel, JSON и изображения;
- использовать OpenAI для анализа контекста, данных и изображений;
- строить `line`, `bar`, `histogram` и `pie` графики в PNG;
- собирать DOCX-отчёты;
- сохранять markdown-summary;
- показывать и скачивать артефакты прямо из чата.

## Переменные окружения

Если `.env` ещё отсутствует, скопируйте в него [`.env.example`](.env.example). Храните ключ только в локальном `.env` или в окружении процесса. `.env` и `реф.env` исключены из Git и контекста сборки Docker. Уже заданные переменные окружения имеют приоритет при загрузке `.env` приложением.

| Переменная | Значение по умолчанию и назначение |
| --- | --- |
| `APP_NAME` | `Data Assistant`, название приложения FastAPI. |
| `APP_HOST` | В настройках Python — `0.0.0.0`, в шаблоне для локального запуска — `127.0.0.1`. При прямом запуске передайте адрес через `uvicorn --host`. Для прослушивания всех интерфейсов при деплое передайте `--host 0.0.0.0`. |
| `APP_PORT` | `8000`. Compose использует значение для порта на хосте. При прямом запуске передайте нужный порт через `uvicorn --port`. |
| `MAX_FILE_SIZE` | `10MB`, лимит одного загружаемого файла. Допустимы целые числа с единицами `B`, `KB`, `MB`, `GB`. |
| `UPLOAD_DIR` | `storage/uploads`, каталог исходных файлов и их метаданных. |
| `OUTPUT_DIR` | `storage/outputs`, каталог графиков, отчётов и сводок. Относительные пути обоих каталогов считаются от корня проекта. При использовании стандартного Compose сохраните эти пути, чтобы данные попадали в bind mounts. |
| `LOG_LEVEL` | `INFO`, уровень подробности логов приложения. |
| `OPENAI_API_KEY` | Секретный ключ API. Без него можно запускать локальные действия через предпросмотр, а чат сообщит, что OpenAI не настроен. |
| `OPENAI_MODEL` | `gpt-5-mini`, идентификатор модели для Responses API. |
| `OPENAI_MAX_HISTORY_MESSAGES` | `8`, число последних сообщений, доступных для формирования контекста модели. |
| `OPENAI_BASE_URL` | Необязательный базовый URL, который читает SDK OpenAI. Если переменная отсутствует, SDK использует свой стандартный адрес. Указывайте только адрес доверенного сервиса с поддержкой Responses API, поскольку туда отправляются ключ и контекст анализа. |

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`.

## Docker

```bash
docker compose up --build -d
```

Dockerfile запускает Uvicorn внутри контейнера на `0.0.0.0:8000`. Compose публикует контейнерный порт только на `127.0.0.1` хоста и использует `APP_PORT` как внешний порт. Значение `APP_HOST` в `.env` само по себе не меняет команду Uvicorn или публикацию порта.

Compose монтирует `storage/chats`, `storage/uploads` и `storage/outputs` из проекта. Чаты, предпросмотры и скачивания доступны браузерной сессии, создавшей данные. После перезапуска откройте прежнюю ссылку на чат в том же профиле браузера и на том же адресе. Старые записи, созданные до появления проверки владельца, сохранены на диске и закрыты через HTTP.

## Локальный бэкап

Из корня проекта в PowerShell выполните:

```powershell
docker compose stop web
try {
    .\.venv\Scripts\python.exe scripts/backup_storage.py --verify-restore
    if ($LASTEXITCODE -ne 0) { throw "Не удалось создать или проверить архив" }
} finally {
    docker compose start web
}
```

Скрипт сохраняет `backups/data-assistant-*.tar.gz` с тремя каталогами хранения. Ключ `--verify-restore` распаковывает новый архив в отдельный временный каталог внутри `backups`, проверяет состав и SHA-256 файлов, затем удаляет временную копию. `.env` исключён. Архив содержит пользовательские данные и метаданные владельцев. Для доступа к восстановленному чату через HTTP по-прежнему нужна исходная cookie браузера.
